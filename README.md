# 📊 Delphi Grade Table

**A table to enter student grades with import & export**

![Delphi](https://img.shields.io/badge/Delphi-EE1F35?style=for-the-badge&logo=delphi&logoColor=white)

</div>

---

## ✨ Features

- Enter first name, last name, midterm and final grades
- Import data
- Export data

## 🚀 Getting Started

1. Open `Project1.dproj` in **Embarcadero Delphi** (RAD Studio).
2. Build & run (`F9`), or launch the prebuilt `Win32/Debug/Project1.exe`.

## 📸 Screenshots

## Description:

A table where first name, last name, midterm grade and final grade can be entered.
The app lets you import and export the entered data.
